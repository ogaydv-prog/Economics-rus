Определение ВВП

Валовой внутренний продукт (ВВП) — рыночная стоимость всех конечных товаров и услуг, произведенных внутри страны за определенный период.

Основное макроэкономическое тождество
Y = C + I + G + NX

4 Способа расчёта ВВП

👛
Затратный метод
По потоку расходов (C+I+G+NX)
🤲
Доходный метод
По первичным доходам факторов
🔄
По добавленной стоимости
Производственный метод (сумма ВДС)
🏷️
По конечной продукции
Без повторного счёта сырья
МАКРОЭКОНОМИЧЕСКОЕ РАВНОВЕСИЕ:
Все 4 метода дают одинаковый конечный результат ВВП.
